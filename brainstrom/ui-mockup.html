🟡🟢 HudWindow
固定在主屏幕顶部居中，距屏幕顶部约 80px；黄=可唤醒(Listening)，绿=记录输入中(Loading/Dictating)。与 MainWindow 互斥，上方模拟器可切换查看。

注：颜色语义 —— 黄=可被唤醒，绿=正在记录用户输入，灰=无响应。Listening(黄)/Loading(绿)/Dictating(绿) 已明确；Unloading 具体过渡视觉（是否闪烁、渐隐时长等）留待下一轮细化，此处按合理假设预览。上方按钮仅切换灯光颜色；要切换"是否显示"请使用页面顶部的 Runtime 状态模拟器。
📌 说明
MainWindow 与 HudWindow 由 Runtime 统一控制、互斥显示：Configure 态只显示 MainWindow，其余四态只显示 HudWindow。关闭 MainWindow 不影响 Runtime 主循环；只有系统托盘菜单里的"退出"才会终止整个 Runtime。
