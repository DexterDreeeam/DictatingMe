SpeakerVerify 双 Gate 改造计划

生成时间 2026-08-01 14:58 +08:00 状态 done 范围 SpeakerVerify 唤醒链路
将 SpeakerVerify 从“严格 KWS + 单一声纹分数”改为“放宽 KWS 候选 + VoiceMatch Gate + 固定声纹 Gate”。三项必须同时通过；灵敏度只调整 KWS 与 VoiceMatch，不调整固定为 0.75 的声纹门槛。

目标

  • SpeakerVerify 的 KWS 搜索宽度与 VoiceMatch 一致，使用 max_active_paths = 16，降低关键词候选漏检。
  • 同一批 3 条注册录音同时生成 VoiceMatch 模板、自校准语音阈值和 CAM++ 声纹 centroid。
    • Gate 1：VoiceMatch 分数达到经灵敏度调整后的 profile 阈值。
    • Gate 2：声纹相似度达到固定阈值 0.75。
  • 最终唤醒必须同时满足 KWS candidate、VoiceMatch Gate 和 Speaker Gate；Preview 复用 VoiceMatch 分数且不持续运行 CAM++。
  • 旧 SpeakerVerify profile 保留在存储中，但因为缺少 VoiceMatch 模板而不可进入 Listening；界面显示需要重新设置，用户重新录制 3 条后生成双 Gate profile。
  • 不新增独立声纹严格度控件，不扩展公开 EvokeScore 事件结构。
