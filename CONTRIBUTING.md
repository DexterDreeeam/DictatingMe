# Contributing to DictatingMe

## License

By submitting a contribution, you agree that it is your original work or that
you have the right to submit it, and that it is licensed under Apache-2.0
without additional terms.

Do not submit proprietary source, models, media, credentials, personal data,
or dependencies that cannot be redistributed under an OSI-approved license.

## Changes

1. Open an issue for substantial behavior or architecture changes.
2. Submit changes through a pull request.
3. Keep changes focused and document user-visible behavior.
4. Update lockfiles when dependencies change.
5. Ensure application and build-script changes are reviewable from source.

Pull requests from non-committers require review by the project reviewer.
Changes to release workflows, dependency manifests, lockfiles, signing
policies, or `.signpath/` files require approval from the signing approver
listed in [CODE_SIGNING_POLICY.md](CODE_SIGNING_POLICY.md).

All project and repository accounts with write or signing access must use
multi-factor authentication.
